## READ 1 — Interior GEH after the insertion backlog clears

### 1a. Boundary exclusion: the hypothesis is (honestly) FALSE for the scored set

**Tag reality first:** the committed 2.1a inventory's `boundary_clipped` tag exists on **2 locations,
both UNMATCHED** — the tag was only computed where matching failed, so it excludes **zero** of the 421
scored links. To avoid hand-picking, the same stub criterion was applied mechanically at link level:

- **Tier A — entry links:** approach edge whose from-node has *no incoming passenger edges* (a network
  entry; its flow is whatever insertion injects). → **2 of 421 links.**
- **Tier B — boundary-cluster locations:** scored location whose junction cluster contains a dead-end /
  one-way stub (the inventory's own signature, via `cluster_nodes`/stub detection). → **0 additional.**

| population | links | GEH<5 |
|---|---|---|
| all scored links (headline) | 421 | **51.8%** |
| interior (excl. Tier A) | 419 | **52.0%** |
| interior (excl. A∪B) | 419 | **52.0%** |

**Why:** the boundary-broken intersections (Markham/Kingston etc.) *failed to match in 2.1a and never
entered the acceptance table*. The scored set was interior all along — contaminant (a) contributes
~0.2 points. Regression check: the method reproduces the committed 51.8% on the original probe edgeData
exactly before any exclusion.

### 1b. Loading knobs: tested both sub-mechanisms — neither recovers GEH

`departLane="best"` is already baked into the calibrated routes (routeSampler `--attributes`), so the
two remaining levers were probed separately (headless, seed 42, counting window 0–7200 unchanged):

| variant | inserted (of 67,808 loaded) | teleports | avg departDelay | GEH<5 (all / interior) |
|---|---|---|---|---|
| accepted baseline (ttt 300) | 57,608 | 5,154 | 130.8 s | **51.8% / 52.0%** |
| V1: `--max-depart-delay 600` | 54,515 | 5,604 | 33.1 s | **48.5% / 48.7%** |
| V2: `--time-to-teleport 120` (no discarding) | 60,156 | 11,320 (2.2×) | 186.0 s | **55.1% / 55.4%** |

- **V1 (discard the backlog): actively worse.** The backlogged vehicles were delivering real late flow;
  discarding them cut inserted volume by ~3,100 and dropped GEH by 3.3 points. The "cleaner" depart
  delay (131→33 s) is queue truncation, not a fix.
- **V2 (flush blockages faster): +3.3 points, bought non-physically.** Inserted volume rose (57,608→60,156) and GEH reached 55.1/55.4%, but teleports DOUBLED to 11,320 — teleported vehicles skip congested stretches and reappear downstream, so part of the gain is queue-jumping, not traffic. Diagnostic value: blockage-starvation accounts for only a few points of the gap.

### The arithmetic ceiling behind the number

Failure texture (203 failing links): **152 are moderate under-delivery** (sim delivers 10–75% of
counted), 31 fully starved, 13 high-volume near-misses, 7 over-delivery. Failing links carry 74% of the
counted volume. Delivery compounds multiplicatively: **build placed 78%** of counted movements ×
insertion ~85% × teleport survival ~91% ≈ 60% of counted volume actually flows. At 78% delivery alone, a
1,000 veh/h link scores GEH ≈ 7.4 — *fail* — so no loading knob can rescue high-volume links past the
build-side gap; the binding constraints are the routeSampler residual (22% unplaced, itself capped by
network capacity) and saturation physics on the clipped net.

### The READ (no decision)

The 51.8% is **not** materially contaminated by either suspected non-model factor: boundary legs were
never scored (+0.2 pts), and both loading interventions fail to move it (V1 discarding: −3.3 pts; V2 aggressive flushing: +3.3 pts to 55.4% interior, and that gain
leans on doubled non-physical teleports). The loading axis spans 48.5–55.4% across its extremes — nowhere near the 70%+ that would have re-framed the claim. The composite-date + clipped-network + build-residual ceiling is real. The presentable
credibility claim is therefore the one already recorded: *interior counted locations, ~52% GEH-validated,
absolute volumes approximate, baseline-vs-scenario like-for-like* — with bbox expansion / signal-plan
import as the structural levers if a higher pass rate is ever required.

## READ 2 — Are calibrated-density conflicts the same animal?

Parsed with parse_ssm's dedupe+breach conventions: **calibrated** (smoke pair) = 393,965 veh-veh
breaching conflicts (195,602 baseline + 198,363 scenario); **synthetic** (pinned pair) = 1,096
(544 + 552). Reconciliation exact: calibrated artifact 201,670 = 198,363 veh-veh + 3,307 ped-PET;
synthetic artifact 573 = 552 + 21. Sample: 200 events, seeded RNG, uniform across the peak
(`read2_summary.json` carries the full list + histograms).

### Value distributions — same shape, shifted mildly toward less-severe

| metric | calibrated | synthetic |
|---|---|---|
| TTC median (q1–q3) | **1.80 s** (0.93–2.43) | **1.21 s** (0.80–2.27) |
| TTC within 10% of threshold (>2.7 s) | 11.4% | 9.0% |
| TTC within 20% (>2.4 s) | 26.4% | 19.4% |
| DRAC median (breachers) | 3.96 m/s² | 4.47 m/s² |
| DRAC within 20% of threshold | 34.7% | 24.0% |
| PET (veh-veh) median | 1.24 s | 1.25 s |
| artifact severity median / q3 | 0.40 / 0.69 | 0.59 / 0.74 |

The TTC histograms are the **same bimodal shape** (a hard-conflict mode near 0.75 s + a soft mode at
2.25–3.0 s); calibrated shifts mass toward the soft mode. **Threshold-marginal jitter is elevated but
not dominant**: ~74% of calibrated TTC breaches are still >20% below threshold.

### Stop-and-go split (ego speed at minTTC) — congestion-dominated at BOTH densities

| regime | calibrated | synthetic |
|---|---|---|
| near-stationary (<10 km/h) | **46.3%** | 34.1% |
| queue (10–30 km/h) | 30.1% | 40.5% |
| moving (>30 km/h) | 23.6% | 25.5% |

~24% of calibrated TTC events have the ego *literally stopped* (<0.1 m/s) at the critical moment.
The moving share is essentially unchanged — the shift is within the congested regimes.

### Composition

| | calibrated | synthetic |
|---|---|---|
| rear_end / crossing / lane_change (veh-veh) | 90.7 / 8.2 / 1.1 % | 86.4 / 12.2 / 1.4 % |
| TTC-only vs TTC+DRAC breaches | 57% / 40% | 39% / 52% |
| ped-PET share of artifact conflicts | **1.6%** | 3.7% |
| conflicts per recorded vehicle | ~7.3 | ~1.4 |

### The READ (no decision)

**Mostly the same animal, at 5× the per-vehicle rate, with a real minority drift toward congestion
jitter.** The distributions keep their shape and most breaches are substantive, so the surrogate has not
categorically changed meaning. But three shifts matter for the safety column's honesty at calibrated
demand: (1) near-stationary events rise to 46% (median severity drops 0.59→0.40) — a growing fraction
measures *queue shockwave exposure*, not free-flow near-misses; (2) fewer events are corroborated by
hard braking (TTC+DRAC 52%→40%); (3) the composition tilts further toward rear-end and away from ped
crossing events (ped share halves), so "safety" at calibrated density is increasingly a car-following
congestion signal. **Implication (finding, not fix):** if calibrated runs ship, the scorecard's safety
cells should carry a demand-conditional note ("at calibrated peak density the surrogate is dominated by
queue interactions; cross-density comparisons of raw counts are not meaningful") — the existing
confidence/note surface can carry it; and any conflicts render-cap must sample by severity strata, not
truncate, or it will visually erase exactly the soft-mode mass that distinguishes the regimes.
