# Optional 90-second demo recording — shot list

The static demo replaces a video for the link-clicking audience; this list exists in case a
recorded walkthrough is ever wanted. Record against the live demo (or `npm run dev`). Rewritten at
V2.7f for the four-stage shell (Build → Watch → Read → Explore); the pre-V2.7 emoji toolbar it once
described is gone. The demo shows finished-run playback only — Act I and Act II (the live physics
beats and the streaming interpretation) need the local backend and never mount in a static export.

1. **(0–15 s) The bare URL.** The EXAMPLE run's run document opens at Read, kicker "EXAMPLE RUN ·
   LOADED READ-ONLY · A PREVIEW, NOT A VERDICT", titled *"Closure at the fire station's doorstep"*.
   Say: "abstract first; every number carries its caveat; the safety column is a near-miss
   surrogate with no direction claimed."
2. **(15–35 s) The doorway.** In section 2.4 select **Car commuters**: the evidence strip — "120
   voices in this run", the cells' basis lines read as text, "Hear Car commuters in Watch →". Click
   it: Watch opens with the feed filtered to that group over the replayed traffic. Say: "every dot
   is a simulated traveler; a few hundred are voices pinned to real trips — anticipated reactions,
   not a poll."
3. **(35–55 s) `?run=multimodal-scenario-20260702T044134Z`.** The 212-voice run: Watch the
   playback, click a dot, then Explore · Discourse — the cascade replay, no tallies. Say: "who
   said what and what moved; the tool never sums it into a verdict."
4. **(55–75 s) Explore · Graphs.** "Two different graphs on purpose: discourse propagation is not
   the chat agent's memory." The exclusion rings are withheld-post metadata, never content.
5. **(75–90 s) `?run=…20260702T044134Z&compare=…20260814T063253Z`.** Explore · Compare: the
   provenance-mismatch guard lines, the "—†" refusal where a delta cannot be claimed. Close on the
   README link.

Discipline: no tallies, no verdicts, no "the majority supports" — the recording sells the
restraint, not a conclusion. Editing, chat, interviews and the room are visibly disabled in the
demo, each carrying the same sentence; do not narrate them as broken.
