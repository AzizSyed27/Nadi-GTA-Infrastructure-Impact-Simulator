# Optional 90-second demo recording — shot list

The static demo replaces a video for the link-clicking audience; this list exists in case a
recorded walkthrough is ever wanted. Record against the live demo (or `npm run dev`).

1. **(0–15 s) The bare URL.** The pinned run loads: moving dots, the ANTICIPATED REACTIONS feed,
   the per-stakeholder scorecard. Say: "every dot is a simulated traveler; a few hundred are
   interviewable voices pinned to real trips — this is a preview of reactions, not a poll."
2. **(15–35 s) The scorecard.** Point at a ± safety cell: "magnitude only — the tool never claims
   a safety direction it can't defend; near-misses, never crash predictions."
3. **(35–55 s) The report.** Open 📄 Report: the preview-not-verdict kicker, the audited slots
   ("every number is code-rendered; the prose is audited for digits, tallies, and verdicts —
   failures retry once, then fail loudly").
4. **(55–75 s) `?run=multimodal-scenario-20260814T063253Z`.** The institutional block: "Toronto
   Fire Services' published mandate, quoted verbatim, read against this run's computed facts —
   east end reachable, west end +29.1 s worst — with the free-flow caveats riding every number."
5. **(75–90 s) 🕸 Graphs.** "Two different graphs on purpose: discourse propagation is not the
   chat agent's memory." Close on the README link.

Discipline: no tallies, no verdicts, no "the majority supports" — the recording sells the
restraint, not a conclusion.
